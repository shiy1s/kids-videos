# Music and SFX register

Prefer original generated music or properly licence-cleared assets. For every external track/SFX, store a sidecar note containing filename, source URL, creator, licence name/version, retrieval date, and any attribution required. Do not use a track unless its licence is verified and documented. Do not infer a licence from a download page alone.

The current gentle background music generator creates procedural music. Keep generated source code with the track metadata; do not describe it as a professionally recorded instrument performance. Audio QA must verify the actual mix and avoid clipping or long silence.
