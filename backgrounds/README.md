# Background assets

Store reusable layered backgrounds by locked location palette: garden, home/playroom, pond/beach, and bedtime. Each scene should have separate sky/backdrop, distant scenery, midground props, and foreground elements to enable parallax. Keep prop layouts uncluttered and child-safe. Use original art only. Current procedural backgrounds are flattened; true layered parallax is not yet verified, so it cannot pass the animation gate.
