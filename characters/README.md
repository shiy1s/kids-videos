# Character asset directory

Store the approved transparent PNG layers and the versioned character bible here. The renderer must reuse these exact assets; do not generate a fresh redesign for each episode.

Required layers per character: body, head, arm_left, arm_right, leg_left, leg_right, eyes_open, eyes_closed, eyebrows_happy, eyebrows_sad, eyebrows_surprised, and mouth_closed/A/E/O/U/M-B-P/F-V/smile/sad.

**Current status:** the codebase has procedural flattened artwork, not a verified full puppet rig. Do not pass the visual-quality gate until the layered assets, animation transforms, expression swaps, and audio-aligned lip-sync are implemented.
