# n8n YouTube Kids

Production-oriented automation for original child-directed cartoon videos.

## Architecture

```
n8n
  |-- free story/scene generator
  |-- safety + duration validation
  |-- GitHub Dispatch + Wait
  v
GitHub Actions
  |-- procedural original cartoon artwork (Pillow)
  |-- local narration (espeak-ng)
  |-- FFmpeg render
  |-- media QC
  |-- artifact
  v
GitHub YouTube Publisher
  |-- downloads artifact
  |-- YouTube OAuth refresh token
  |-- uploads PRIVATE + Made for Kids
  |-- returns video ID to n8n
  v
n8n tracking
```

## No paid AI API

The core pipeline does not require OpenAI, ChatGPT API, Gemini API, or another paid AI API.

Stories are generated by a deterministic free n8n content generator. Cartoon artwork is generated locally with Pillow. Narration is generated locally with espeak-ng. FFmpeg performs the final render.

No `OPENAI_API_KEY` is required.

## Publishing safety

YouTube publishing is performed by GitHub using the existing OAuth secrets. The upload is hard-coded to `private` and `selfDeclaredMadeForKids=true`. Automatic public publishing is not enabled.

YouTube's `videos.insert` API supports OAuth upload and the `status.privacyStatus` and `status.selfDeclaredMadeForKids` fields. See the official YouTube API documentation.

## Isolation
